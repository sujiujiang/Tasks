# ❤️我的Markdown学习笔记（＋进阶笔记）

## 1️⃣什么是Markdown
&emsp;&emsp;Markdown 是一种轻量级标记语言，用于描述文本排版格式。简单说，Markdown是一种“有格式的纯文本”写法，文件常以```.md```后缀，而且几乎所有编辑器、网站、软件都能打开。

## 2️⃣Markdown的基础语法及补充
1. 我作为初学者所第一次接触到并使用的编辑器有入门教程和基础语法，我贴在这
[https://markdown.com.cn/editor/](https://example.com)
（比如：#是标题 `**`**加粗** `*`*斜体* `-`无序列表......）
3. 此项作为补充长期使用Markdown中学习接触到的好用的拓展语法：
-  `&emsp;&emsp;`可以实现开头空两格的效果（一个&emsp；则代表一个中文字符长度）
-  某行文字下方纯是=，则会升级为一级标题；纯是-则会升级成二级标题
-  ......

## 3️⃣Markdown的局限及替代方案
&emsp;&emsp;Markdown注重“作者优先”，使得创作回归内容，但就存在
了相应的局限：
1. 精细排版弱：很难做到复杂的文字缩进、精确间距、多栏布局；
2. 渲染不统一：同样一份文档，在 GitHub、在线编辑器、手机上显示效果不一样;
3. 缺交互能力：做不了动态动画，表现形式单一生硬；
4. 样式控制差：很难像 Word、PPT 那样自由调字体大小、颜色。
-  虽然Markdown也可以做简易流程图，但是最好还是用专门流程图软件制作表现力更好一些，如：XMind、MindSpark...
-  精细的排版报告：我们熟悉的word、PowerPoint...
-  手绘类笔记：笔记软件、Procreate...
-  复杂表格：Excel...
